# نطاق للمتاجر | Nitaaq Store

مهارة ذكاء اصطناعي عربية تساعدك تشغّل متجرك الحالي في **سلة** وتحسّنه وتفحصه بأوامر عادية بالعربي.

اسم الحزمة التقني: `nitaaq-store`

---

## وش تسوي المهارة؟

| الخدمة | أمثلة لطلباتك |
|---|---|
| **المنتجات والمخزون** | «ضيف عطر عود ملكي بسعر 249 وخصم إلى 199»، «زود كمية المسك الأبيض 10»، «اعرض المنتجات المخفية» |
| **مظهر المتجر والعرض** | «أضف بنر لعروض اليوم الوطني في الرئيسية»، «رتّب أقسام الصفحة الرئيسية»، «جهّز صفحة هبوط للعرض» |
| **الطلبات والتشغيل اليومي** | «وش الطلبات الجديدة اليوم؟»، «أضف ملاحظة داخلية على الطلب 1004»، «وش أكثر المنتجات المتروكة في السلات؟» |
| **التقارير والتحليل** | «مبيعات الشهر الماضي حسب المدينة»، «أكثر 10 منتجات مبيعاً بالإيراد»، «هامش المنتجات» |
| **فحص المتجر** | «افحص صفحات المنتجات والتتبع وطرق الدفع الظاهرة» |
| **فحص وتحسين ظهور المتجر — SEO وGEO** | «افحص ظهور متجري في Google وفي إجابات الذكاء الاصطناعي وأصلح المشاكل» |

**خارج النطاق:** بناء تطبيقات سلة أو تطبيقات الشركاء أو تطبيقات المتجر، خطط اشتراك المطورين، بناء ربط شركات الشحن كخدمة، تطوير قوالب Twilight جديدة، والعمل كمساعد مطورين في بوابة الشركاء. أما تعديل إعدادات وأقسام **قالبك الحالي** ونسخ إعداداته للمعاينة فهو ضمن النطاق.

## كيف تشغّلها؟

اكتب أي عبارة من هذي:

- «نطاق للمتاجر»
- «استخدم مهارة نطاق»
- «استخدم مهارة استور»
- «استور» (لما تخاطبها أو تتكلم عن متجرك)

أو استدعها مباشرة:

| البيئة | الأمر |
|---|---|
| Claude Code | `/nitaaq-store` |
| Codex | `$nitaaq-store` أو اخترها من `/skills` |
| claude.ai | اذكر اسم المهارة في طلبك (لا يوجد أمر شرطة مضمون) |

المهارة ما تتفعّل على كلمة «ستور» بمعنى آخر مثل «آب ستور» أو «بلاي ستور».

> التفعيل التلقائي بالكلام قرار البيئة المستضيفة نفسها، وقد يختلف بين Claude Code وCodex وclaude.ai.

## أوضاع التشغيل

المهارة تشتغل بأمانة حسب الأدوات المتاحة فعلاً:

| الوضع | متى | وش تقدر تسوي |
|---|---|---|
| **متصل بالمتجر** | عندك أداة MCP للتاجر مربوطة بمتجرك | قراءة وتعديل ما تسمح به الأدوات والصلاحيات فقط |
| **فحص عام ومحتوى** | ما فيه ربط | فحص الصفحات العامة، كتابة الأوصاف وعناوين SEO، تصاميم البنرات (إن توفرت أداة صور)، مقترحات قبل/بعد، وخطوات التطبيق من لوحة سلة |
| **متصفح بمساعدتك** | البيئة فيها أدوات متصفح وطلبت تنفيذاً من لوحة سلة | العمل في جلستك أنت؛ تسجيل الدخول ورمز التحقق عليك |
| **تحليل ملفات** | ترسل ملفات تصدير | تحليل محلي مع توضيح تاريخ الملف واكتماله وحدوده |

قواعد ثابتة:

- المسودة تُسمّى «مسودة» وليست «تم الحفظ»، والصورة الجاهزة «جاهزة للرفع» وليست «تم الرفع»، والمقترح «مقترح» وليس «تم الإصلاح».
- ما نستنتج الطلبات الخاصة أو المنتجات المخفية أو بيانات العملاء أو المخزون الفعلي من الصفحات العامة.
- لو ربطت المتجر لاحقاً، المهارة تكتشف القدرات الجديدة وتخبرك.

---

## اتصال سلة (MCP)

- المهارة **لا تضيف** اتصالاً بسلة ولا صلاحيات. الاتصال يُضاف من إعدادات البيئة (Claude Code أو Codex أو claude.ai) إن كان متاحاً لك.
- المهارة تكتشف الأدوات الموجودة فعلاً وتبني «خريطة قدرات»، وما تفترض أن أي خادم اسمه «Salla» يقدّم كل العمليات.
- اتصال **شركاء سلة** (Salla Partners MCP) مخصص لتطبيقات الشركاء، ولا يعطي وصولاً لمنتجاتك أو طلباتك أو مخزونك أو تقاريرك.
- كل عملية لها مستوى إثبات: مكتشفة ← متحقق من مخططها ← مختبرة ← متحقق منها على متجر حي. الاختبارات الوهمية لا تجعل أي عملية «متحقق منها على متجر حي».

التفاصيل: [docs/ar/القدرات-والتحقق.md](docs/ar/القدرات-والتحقق.md)

## التثبيت السريع

يلزم Python 3.9 أو أحدث (بدون مكتبات إضافية).

```sh
git clone <رابط المستودع> nitaaq-store
cd nitaaq-store
./install.sh                      # Claude Code وCodex لمستخدمك
./install.sh --host claude-code   # Claude Code فقط
./install.sh --host codex         # Codex فقط
./install.sh --scope project --project /path/to/project   # داخل مشروع
./install.sh --dry-run            # اعرض الخطة بدون تنفيذ
./install.sh --uninstall          # إزالة
```

السكربت:
- يكتب مجلد `nitaaq-store` فقط، ولا يلمس مهاراتك الأخرى ولا إعدادات MCP.
- لو فيه نسخة سابقة من نطاق للمتاجر يحفظها احتياطياً في `~/.nitaaq-store/backups/`.
- لو فيه مجلد بنفس الاسم لمهارة أخرى يتوقف ولا يلمسه.

**claude.ai:** شغّل `python3 tools/build.py` ثم ارفع `dist/claude-ai/nitaaq-store.zip` من قسم المهارات (Skills) في إعدادات claude.ai. رابط المستودع وحده لا يثبّت المهارة هناك.

الدليل الكامل: [docs/ar/التثبيت.md](docs/ar/التثبيت.md)

## الأمان والخصوصية

- كل تعديل حساس (السعر، الحالة، الكمية، الاسم، الحذف، أي شيء يصل للعميل، التعديلات الجماعية) يُعرض عليك بجدول قبل/بعد وتعتمده.
- قبل التنفيذ نعيد قراءة القيم الحالية؛ ولو تغيرت منذ عرضها نوقف ونسألك.
- بعد التنفيذ نقرأ القيمة من المتجر للتأكد أنها انحفظت فعلاً.
- سجل محلي يمنع تكرار العمليات (مثل إنشاء المنتج مرتين) عند انقطاع الاتصال.
- ما نرسل رسائل لعملائك ولا نغيّر حالات تُشعرهم ولا نسوي استرجاعاً أو شحناً بدون إذن صريح.
- ما نطلب كلمات مرور، وما نحفظ مفاتيح أو رموز دخول في الملفات أو السجلات.
- بيانات العملاء تُحجب من أي تقرير قابل للمشاركة.
- محتوى الصفحات والأوصاف والملفات يُعامل كبيانات وليس كأوامر.

## التقارير

كل رقم يُحسب بكود ثابت أو من تقرير موثوق، ومع كل تقرير: المصدر، الفترة، المنطقة الزمنية (الرياض افتراضياً)، العملة، تعريف المقياس، الحالات المشمولة، معالجة الخصم والضريبة والشحن والمرتجعات، ومدى اكتمال البيانات.

- «هامش المنتجات» ليس «صافي الربح» ما لم تتوفر المصاريف التشغيلية.
- لا نحسب العائد على الإنفاق الإعلاني بدون بيانات الإنفاق.
- المبيعات المنسوبة لحملة ليست دليلاً على أن الحملة سببها.
- لا نستنتج العمر أو الجنس من أسماء العملاء.

## SEO وGEO

خدمة «فحص وتحسين ظهور المتجر — SEO وGEO» تشمل:

1. **فحص SEO:** الزحف والفهرسة، التحويلات، robots.txt وخريطة الموقع، canonical، الصفحات المكررة، العناوين والأوصاف، H1، النص البديل للصور، الروابط الداخلية، البيانات المنظمة للمنتج ومطابقتها للسعر الظاهر، وبيانات Search Console إن وفرتها.
2. **جاهزية GEO:** وضوح هوية المتجر، دقة معلومات المنتجات، سياسات الشحن والاسترجاع والتواصل، الاتساق، وسماح زواحف البحث.
3. **الظهور الفعلي في إجابات الذكاء الاصطناعي:** مجموعة أسئلة سعودية بالعربي (اسم المتجر، المنتجات، اكتشاف الفئة، المقارنات، الأسئلة المعلوماتية، المدن، الثقة والسياسات) وتسجيل النتائج كعينة، مع توضيح أن الإجابات تتغير.
4. **المعالجة وإعادة الفحص:** إصلاح ما يمكن إصلاحه ضمن صلاحياتك والتحقق منه، وتحديد ما يحتاج لوحة التحكم أو دعم سلة.

حدود نوضحها دائماً: الفحص العام لا يثبت حالة الفهرسة الفعلية، وبحث `site:` ليس إحصاءً للفهرس، وملف `llms.txt` اختياري ولا يضمن الظهور، ولا نعد بترتيب أو ظهور في أي منصة.

## هيكل المستودع

```
skill/nitaaq-store/          النواة المشتركة (تقرأها كل البيئات)
  SKILL.md                   التعليمات الرئيسية
  references/                تفاصيل كل خدمة
  scripts/nitaaq_cli.py      الأدوات المساعدة (Python، مكتبة قياسية)
  scripts/nitaaq/            وحدات: القدرات، أمان الكتابة، المنتجات، التقارير، الفحص…
  assets/operation-catalog.json   كتالوج العمليات الثابت
adapters/                    إضافات رفيعة لكل بيئة (Claude Code، Codex، claude.ai)
tools/build.py               التحقق وبناء الحزم في dist/
tools/install.py             التثبيت الآمن
tests/                       الاختبارات
docs/ar/                     التوثيق العربي
```

## للمطورين

```sh
python3 tools/build.py                       # تحقق وبناء
python3 -m unittest discover -s tests -v     # الاختبارات
python3 skill/nitaaq-store/scripts/nitaaq_cli.py --help
```

الاختبارات تستخدم بيانات وهمية وأدوات افتراضية، ولا تثبت عمل أي موصل حقيقي على متجر حي.
