# تثبيت نطاق للمتاجر

المسارات أدناه مأخوذة من التوثيق الرسمي لكل بيئة (تمت مراجعتها في 2026-09-30). إذا تغيّر التوثيق لاحقاً فالمرجع هو التوثيق الرسمي.

## المتطلبات

- Python 3.9 أو أحدث لتشغيل الأدوات المساعدة وسكربت التثبيت. لا توجد مكتبات إضافية.
- للعمل على بيانات متجرك الخاصة: اتصال MCP للتاجر أو أدوات متصفح في البيئة. المهارة وحدها لا توفر أياً منهما.

## 1) Claude Code

### أ) كـ plugin من سوق nitaaq (موصى به)

المستودع نفسه سوق plugins (`.claude-plugin/marketplace.json`).

```
/plugin marketplace add essam12e/nitaaq-store
/plugin install nitaaq-store@nitaaq
```

- الأمر يصبح `/nitaaq-store:nitaaq-store` لأن مهارات الـplugin تأخذ اسمه كبادئة.
- تم التحقق: `claude plugin validate` للسوق والـplugin، وتثبيت فعلي بـ Claude Code 2.1.285 أظهر المهارة `nitaaq-store`.
- المستودع عام حالياً؛ لو جعلته خاصاً يحتاج كل مستخدم صلاحية قراءة عليه.

### ب) كمجلد مهارة (سكربت التثبيت)

| النطاق | المسار |
|---|---|
| لمستخدمك (كل المشاريع على هذا الجهاز) | `~/.claude/skills/nitaaq-store/` |
| داخل مشروع (يُرفع مع المستودع) | `<المشروع>/.claude/skills/nitaaq-store/` |

```sh
./install.sh --host claude-code
# أو داخل مشروع:
./install.sh --host claude-code --scope project --project /path/to/project
```

بعدها: اكتب `/nitaaq-store` أو «نطاق للمتاجر». Claude Code يكتشف تغييرات المهارات أثناء الجلسة عادةً؛ إن لم تظهر أعد تشغيل الجلسة.

ملاحظات:
- جلسات Claude Code السحابية وCowork لا تقرأ `~/.claude/skills` من جهازك؛ استخدم التثبيت داخل المشروع (`.claude/skills` في المستودع) أو فعّل المهارة في حسابك على claude.ai.
- حزمة Claude Code تضيف حقل `argument-hint` فقط فوق النواة المشتركة.

## 2) Codex

| النطاق | المسار |
|---|---|
| لمستخدمك | `~/.agents/skills/nitaaq-store/` |
| داخل مستودع | `<المستودع>/.agents/skills/nitaaq-store/` |

```sh
./install.sh --host codex
```

بعدها: اكتب `$nitaaq-store` أو اخترها من `/skills`. الحزمة تضيف `agents/openai.yaml` (الاسم المعروض، الوصف القصير، اللون) ولا تمنح أي أدوات.

## 3) claude.ai (الدردشة)

1. `python3 tools/build.py`
2. من claude.ai افتح الإعدادات ثم قسم المهارات (Skills) وارفع الملف `dist/claude-ai/nitaaq-store.zip`. (اسم القائمة قد يختلف حسب إصدار التطبيق.)
3. يجب أن تكون ميزة Skills مفعّلة لحسابك أو مؤسستك، وتنفيذ الكود متاحاً لتشغيل الأدوات المساعدة.

حدود claude.ai:
- رابط المستودع وحده لا يثبّت المهارة؛ لازم رفع الملف.
- لا يوجد أمر `/nitaaq-store` مضمون؛ اذكر اسم المهارة في طلبك.
- الوصول للإنترنت من بيئة تنفيذ الكود قد يكون محدوداً، فقد لا يعمل فحص الروابط العامة بالأداة المساعدة؛ عندها تعتمد المهارة على أدوات البحث/الجلب في المحادثة إن وجدت أو على ملفاتك.
- يمكن استخدام نفس الملف مع واجهة Skills في Claude API حسب توثيقها.

## 4) نسخ يدوي (أي بيئة تدعم صيغة Agent Skills)

انسخ المجلد `dist/<البيئة>/nitaaq-store` كما هو إلى مجلد المهارات في البيئة. اسم المجلد يجب أن يبقى `nitaaq-store` لأنه يطابق حقل `name`.

## ما الذي لا يفعله سكربت التثبيت

- لا يعدّل `settings.json` أو `.mcp.json` أو `~/.claude.json` أو `~/.codex/config.toml`.
- لا يحذف أو يستبدل مهارات أخرى.
- لا يكتب عبر رابط رمزي (symlink) بنفس الاسم.
- النسخة الاحتياطية تُحفظ في `~/.nitaaq-store/backups/` خارج مجلدات المهارات حتى لا تظهر كمهارة مكررة.

## التحقق من التثبيت

```sh
./install.sh --dry-run
python3 ~/.claude/skills/nitaaq-store/scripts/nitaaq_cli.py --version
```

وفي المحادثة: «نطاق للمتاجر، وش تقدر تسوي الآن؟» — المهارة ستكتشف الأدوات المتاحة وتخبرك بالوضع الحالي.
